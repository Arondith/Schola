# Schola Website

A functional, responsive vanilla HTML/CSS/JavaScript implementation based on the supplied Schola Figma screenshots.

## Run it

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the smoothest local-development experience, use VS Code + Live Server, but no build step is required.

## Demo flow

- Login → Dashboard
- Sidebar navigation:
  - Dashboard
  - Study Planner
  - Resource Library
  - Practice
  - Study Groups
  - Profile
- Study Planner:
  - Task completion
  - Add task
  - Focus timer
- Practice:
  - Start HCI II flashcard deck
  - Cycle through cards
- Profile:
  - Open Calculus Integration Notes
  - Mark notes reviewed
- Study Groups:
  - Open Science/T.L.E groups
  - Create a new study group
- Resource Library:
  - Open resources
  - Save shared resource
- Quick Add:
  - Task, resource, or study group

## Files

- `index.html` — app entry
- `styles.css` — full responsive design
- `app.js` — navigation and interactions
- `assets/login-illustration.png` — cropped from the supplied design screenshot

## Notes

This is a front-end prototype. Login/social sign-in, data storage, AI chat, and cloud file sharing are demonstrated in the UI but do not connect to a real backend.
