# Schola

Schola is a responsive front-end study platform prototype built with vanilla HTML, CSS, and JavaScript.

This project was developed as a **school project in collaboration with one project partner**. It demonstrates an academic dashboard with tools for planning, study resources, practice activities, study groups, and profile management.

## Project structure

The main website is located in:

`Schola_Website/schola-website/`

Key files:

- `index.html` — application entry point
- `styles.css` — responsive styling
- `app.js` — navigation and interactive behavior
- `assets/` — images and supporting assets

## Features

- Login and dashboard interface
- Study planner and task completion
- Focus timer
- Resource library
- Flashcard practice
- Study groups
- Profile and notes interactions
- Quick-add actions

## Running locally

1. Clone or download the repository.
2. Open `Schola_Website/schola-website/index.html` in a browser.
3. For a smoother development workflow, open the folder in VS Code and use Live Server.

No build step is required.

## Status

This repository currently contains a front-end prototype. Backend services such as authentication, persistent storage, AI chat, and cloud file sharing are represented in the interface but are not yet connected to production services.
